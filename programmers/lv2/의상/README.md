- 소요 시간:
- 결과: AI 풀이 참고 → 다시 풀기 필요

## 접근 방법

1. 딕셔너리로 종류별 옷 개수 세기 (완주하지 못한 선수와 같은 `get(key, 0) + 1` 패턴)
2. 종류마다 선택지는 **옷 개수 + 1** (+1은 "그 종류는 안 입음")
3. 모든 종류의 선택지를 곱함
4. 전부 안 입는 경우 1가지를 빼기 (최소 한 개는 입어야 하므로)

## 막혔던 부분

- 감이 안 와서 AI 풀이를 참고함
- 핵심은 코드가 아니라 **경우의 수 공식**

## 다른 풀이에서 배운 점

- 예시: 모자 2개, 안경 1개
  - 모자: 모자1 / 모자2 / 안 씀 → 3가지
  - 안경: 안경1 / 안 씀 → 2가지
  - 3 × 2 = 6, 둘 다 안 쓰는 1가지 빼면 **5**
- "각 그룹에서 하나 고르거나 안 고르기" 유형이 나오면 `(개수 + 1)`을 곱하고 `- 1`
