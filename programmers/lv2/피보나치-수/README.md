## 접근 방법

- `dp[i] = dp[i-1] + dp[i-2]`: 앞에서 구한 값을 저장해 두고 재사용 (DP)
- 재귀로 풀면 같은 값을 계속 다시 계산해서 시간 초과

## 막혔던 부분

- AI 풀이를 참고함

## 다른 풀이에서 배운 점

- 나머지는 **마지막에 한 번**이 아니라 **매번** 구하는 게 정석
  - 파이썬은 큰 수도 계산되지만 n=100,000이면 수가 엄청 커져서 느려짐
  - 다른 언어는 오버플로우가 나서 틀림
- `(a + b) % m == ((a % m) + (b % m)) % m`이라 중간에 나눠도 결과가 같음

```python
for i in range(2, n + 1):
    dp[i] = (dp[i-1] + dp[i-2]) % 1234567
```
