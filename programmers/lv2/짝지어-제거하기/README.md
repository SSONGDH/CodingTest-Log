## 접근 방법

- 글자를 하나씩 스택에 쌓다가, **스택 맨 위 글자와 지금 글자가 같으면** 짝이므로 둘 다 없앰 (`pop`)
- 다르면 쌓음 (`append`)
- 끝났을 때 스택이 비어 있으면 전부 짝지어 제거된 것 → `1`

## 막혔던 부분

- 스택 개념을 몰랐음
- `stack[-1]`의 의미를 몰랐음

## 다른 풀이에서 배운 점

### `stack[-1]` = 리스트의 마지막 원소

```python
stack = ['b', 'a', 'a']
stack[-1]   # 'a'  (맨 뒤)
stack[-2]   # 'a'  (뒤에서 두 번째)
stack[0]    # 'b'  (맨 앞)
```

- 음수 인덱스는 뒤에서부터 셈. `stack[len(stack) - 1]`과 같음
- 스택에서는 마지막에 넣은 값 = 맨 위 값이라 `stack[-1]`로 확인함

### `if stack and ...`

- 빈 리스트에서 `stack[-1]`을 하면 `IndexError`
- 빈 리스트는 `False`로 취급되므로 `stack and`를 앞에 두면 비어 있을 때 뒤쪽 비교를 아예 안 함

### 동작 예시: `"baabaa"`

| 글자 | 스택 맨 위 | 동작 | 스택 |
|---|---|---|---|
| b | (없음) | 넣기 | `[b]` |
| a | b | 넣기 | `[b, a]` |
| a | a | **같음 → 빼기** | `[b]` |
| b | b | **같음 → 빼기** | `[]` |
| a | (없음) | 넣기 | `[a]` |
| a | a | **같음 → 빼기** | `[]` |

- 스택이 비었으므로 `1`

### 같은 뼈대 문제

- **같은 숫자는 싫어** (Lv1): `answer[-1]`과 비교해서 다를 때만 넣기
- **올바른 괄호** (Lv2): `(`면 넣고 `)`면 빼기
- "직전 값과 비교해서 없애거나 쌓기" 유형은 전부 스택

### 마지막 return 줄이기

```python
return 1 if not stack else 0
```
