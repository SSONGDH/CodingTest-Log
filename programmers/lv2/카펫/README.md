## 접근 방법

- 노란 격자의 크기를 `i × (yellow // i)`로 두고, `yellow`의 약수를 하나씩 대입
- 갈색 격자 수 = 노란 격자 둘레 + 모서리 4칸 = `2 * (가로 + 세로) + 4`
- 이 값이 `brown`과 같으면 전체 카펫 크기는 노란 격자 가로·세로에 각각 `+2`

## 막혔던 부분

- 가로 ≥ 세로 순서를 맞추는 부분
- 반복 범위를 어디까지 잡아야 하는지

## 내 풀이의 버그

나중에 맞는 값이 이전 값을 덮어쓰는 방식이라, **큰 약수까지 반복이 닿지 않으면 가로·세로가 뒤집힘**.

예: `brown=14, yellow=4` (노란 격자 4×1, 정답 `[6, 3]`)

| i | 조건 만족? | answer |
|---|---|---|
| 1 | O | `[3, 6]` (뒤집힘) |
| 2 | X | `[3, 6]` |
| 3 | 약수 아님 | `[3, 6]` |

- 범위가 `range(1, 4)`라 `i=4`가 안 돌아서 `[6, 3]`으로 덮어써지지 않음 → 오답 `[3, 6]`
- 노란 격자가 한 줄(세로 1)이고 `yellow ≥ 4`면 항상 발생

## 다른 풀이에서 배운 점

### 개선 풀이

```python
def solution(brown, yellow):
    for h in range(1, int(yellow ** 0.5) + 1):
        if yellow % h == 0:
            w = yellow // h
            if 2 * (w + h) + 4 == brown:
                return [w + 2, h + 2]
```

- `h`를 **세로(작은 쪽)**로 정하면 `w = yellow // h`가 항상 `h` 이상 → 순서 고민 불필요
- 찾자마자 `return` → 덮어쓰기에 기대지 않음

### 약수는 √n까지만

- 약수는 `(i, n // i)` 쌍으로 나오고, 쌍의 작은 쪽은 항상 `√n` 이하
- `range(1, int(n ** 0.5) + 1)`만 돌고 큰 쪽은 `n // i`로 구하면 됨
