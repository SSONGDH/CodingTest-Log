# 자주 하는 실수 모음

| 문제 | 실수 내용 | 교훈 |
|---|---|---|
| 게임 맵 최단거리 | `queue.append([(nx, ny, d)])`처럼 대괄호를 써서 `ValueError: not enough values to unpack` | 만들 때는 `deque([...])`, 넣을 때는 `append((...))` |
| 게임 맵 최단거리 | `maps[nx][ny]`로 접근 | 2차원 리스트는 `maps[행][열]` = `maps[y][x]`. 헷갈리면 `r`, `c`로 이름 짓기 |
| 게임 맵 최단거리 | 범위 조건과 `visited` 크기에 `-1`을 붙여 마지막 줄을 못 감 | 인덱스 범위는 `0 <= i < 길이` |
| 게임 맵 최단거리 | 크기 `(len(maps[0]), len(maps))`를 도착 좌표로 착각 | 마지막 인덱스는 `길이 - 1` |
| 같은 숫자는 싫어 | 다음 값과 비교하다 마지막 원소 처리가 복잡해짐 | 넣은 마지막 값 `answer[-1]`과 비교 |
| K번째수 | 1부터 시작하는 번호를 인덱스로 바로 씀 | 문제 번호 → 인덱스는 `-1` |
| 보호소에서 중성화한 동물 | `LIKE 'A%' OR 'B%'`처럼 컬럼을 한 번만 씀 | `COL LIKE 'A%' OR COL LIKE 'B%'`, AND와 섞으면 괄호 |
