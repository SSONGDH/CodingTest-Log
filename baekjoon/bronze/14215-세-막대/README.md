## 접근 방법

- 세 길이를 정렬해서 `num[2]`가 가장 긴 막대가 되게 함
- 삼각형 조건(두 변의 합 > 나머지 한 변) 3개를 모두 만족할 때까지 가장 긴 막대를 1씩 줄임
- 줄일 때마다 다시 `sort()`해서 가장 긴 막대를 맨 뒤로 보냄
- 조건을 만족하는 순간 세 길이의 합을 출력

## 다른 풀이에서 배운 점

### 정석 풀이

```python
a, b, c = sorted(map(int, input().split()))
if c >= a + b:          # 가장 긴 막대가 너무 길면
    c = a + b - 1       # 나머지 두 개 합보다 1 작게 줄이기
print(a + b + c)
```

- 정렬하면 `a <= b <= c`라서 확인할 조건은 **`a + b > c` 하나뿐** (나머지 두 조건은 항상 참)
- 조건을 만족하지 않을 때 `c`가 될 수 있는 가장 큰 값은 `a + b - 1` → 반복 없이 바로 계산

```python
# X: 1씩 줄이며 조건 확인 반복
while not (a + b > c):
    c -= 1

# O: 줄일 양을 한 번에 계산
if c >= a + b:
    c = a + b - 1
```

| | 제출 풀이 | 정석 풀이 |
|---|---|---|
| 방법 | 1씩 줄이며 반복 | 공식으로 바로 계산 |
| 반복 횟수 | 최대 `c - (a + b - 1)`번 | 0번 |
| 확인하는 조건 | 3개 | 1개 (`a + b > c`) |
| 시간복잡도 | O(c) | O(1) |

- 입력이 100 이하라 반복해도 통과했지만, 길이가 10억이면 시간 초과
- 줄이는 동안 가장 긴 막대는 계속 `c`라서 매번 다시 `sort()`할 필요도 없음
- "삼각형 만들기" 문제는 **정렬 후 `가장 긴 변 < 나머지 두 변의 합`** 하나만 보면 됨
