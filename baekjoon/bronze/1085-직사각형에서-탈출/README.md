# 1085. 직사각형에서 탈출

- 링크: https://www.acmicpc.net/problem/1085
- 난이도: Bronze III
- 분류: 수학, 기하학
- 푼 날짜: 2026-11-24
- 소요 시간:
- 결과: 성공

## 접근 방법

- 경계선까지 가는 방법은 왼쪽(`x`), 아래(`y`), 오른쪽(`w - x`), 위(`h - y`) 4가지
- 가운데(`w/2`, `h/2`)를 기준으로 어느 쪽에 더 가까운지 나눠서 `if`문으로 비교

## 막혔던 부분

- 없음 (조건 분기가 4갈래로 길어짐)

## 다른 풀이에서 배운 점

- 가운데 기준으로 나눌 필요 없이 **4개 거리 중 최솟값**이 답

```python
x, y, w, h = map(int, input().split())
print(min(x, y, w - x, h - y))
```

- "여러 후보 중 가장 작은 것"은 `if`로 하나씩 비교하지 말고 후보를 전부 `min()`에 넣기 (폰켓몬과 같은 패턴)
- 변수 이름을 `a, b, c, d` 대신 문제의 `x, y, w, h`로 쓰면 식이 바로 읽힘
