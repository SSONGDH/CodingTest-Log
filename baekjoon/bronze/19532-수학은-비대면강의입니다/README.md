# 19532. 수학은 비대면강의입니다

- 링크: https://www.acmicpc.net/problem/19532
- 난이도: Bronze II
- 분류: 브루트포싱, 수학
- 푼 날짜: 2026-11-24
- 소요 시간:
- 결과: 성공

## 접근 방법

- 답 `x`, `y`가 -999 ~ 999 정수라는 조건 → 두 범위를 이중 for문으로 전부 대입
- 두 식 `a*i + b*j == c`, `d*i + e*j == f`를 모두 만족하는 `(i, j)` 출력
- 해가 하나뿐이라 출력은 한 번만 됨

## 막혔던 부분

## 다른 풀이에서 배운 점

- 정석 풀이와 같은 방식 (브루트포스 단계 문제)
- 확인 횟수 1999² ≈ 400만 → 파이썬도 1초 안에 가능 (560 ms)
- 답을 찾은 뒤에도 끝까지 돌고 있음 → 이중 for문은 `break` 하나로 못 빠져나오니 함수로 만들어 `return`하면 바로 끝남
- "답의 범위가 작게 주어짐" = 전부 대입해 보라는 신호
- 연립방정식 공식(크래머 공식)으로 반복 없이 풀 수도 있다는 것만 알아두기
