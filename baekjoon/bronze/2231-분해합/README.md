# 2231. 분해합

- 링크: https://www.acmicpc.net/problem/2231
- 난이도: Bronze II
- 분류: 브루트포싱
- 푼 날짜: 2026-11-24
- 소요 시간:
- 결과: 성공

## 접근 방법

- 1부터 N까지 모든 수를 생성자 후보로 확인
- `% 10`으로 마지막 자리를 떼고 `// 10`으로 지우는 걸 반복해서 자릿수를 리스트에 모음
- `후보 + sum(자릿수) == N`인 첫 수가 가장 작은 생성자 → 출력 후 `break`
- 끝까지 못 찾으면 `flag`가 0이라 0 출력

## 다른 풀이에서 배운 점

- 정석 풀이와 같은 방식 (작은 수부터 전부 확인하는 브루트포스)
- 자릿수 합은 최대 `9 × 자릿수`라서 생성자는 `N - 9 * len(str(N))` 이상
  - 시작을 여기서 하면 확인 범위가 100만 개 → 63개 이하로 줄어듦
- 변수 이름을 `list`로 쓰면 내장 함수 `list()`를 덮어씀 → `digits`처럼 다른 이름 쓰기
- 자릿수 합은 `sum(map(int, str(i)))`로도 구할 수 있음
- `for`가 `break` 없이 끝났을 때 실행되는 `for ... else`를 쓰면 `flag` 변수 없이 "못 찾음" 처리 가능
