# 1018. 체스판 다시 칠하기

- 링크: https://www.acmicpc.net/problem/1018
- 난이도: Silver III
- 분류: 브루트포싱, 구현
- 푼 날짜: 2026-11-24
- 소요 시간:
- 결과: 성공

## 접근 방법

- 8×8로 자를 수 있는 모든 시작점 `(y, x)`를 이중 for문으로 확인 (`(N-7) × (M-7)`개)
- 시작점마다 두 가지 체스판과 비교해서 다시 칠할 칸 수 세기
  - `check_W`: 행·열이 둘 다 짝수 또는 둘 다 홀수인 칸이 W
  - `check_B`: 같은 칸이 B
- 모든 시작점에서 `min(check_B, check_W)`의 최솟값이 답
- 짝홀을 전체 보드 기준으로 보지만 W/B 두 패턴을 다 확인하므로 시작점이 홀수여도 결과는 같음

## 막혔던 부분

## 다른 풀이에서 배운 점

- 정석 풀이와 같은 방식 (모든 시작점 × 두 가지 색 패턴 확인)
- 칸 색은 `(i + j) % 2`로 한 번에 판단 가능 → 짝홀 `if` 4갈래가 1줄로 줄어듦
- W로 시작할 때 다시 칠할 칸이 `k`개면 B로 시작할 때는 `64 - k`개 → 한 패턴만 세도 됨
- "큰 판에서 고정 크기 영역 고르기" = 시작점 이중 for문 + 영역 검사 함수
