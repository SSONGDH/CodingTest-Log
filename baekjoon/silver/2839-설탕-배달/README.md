## 접근 방법

- 5kg 봉지 개수 `i`(0 ~ N//5), 3kg 봉지 개수 `j`(0 ~ N//3)를 이중 for문으로 전부 확인
- `5i + 3j == N`인 경우 중 `i + j`의 최솟값을 저장
- 한 번도 못 찾으면 처음 값 `-1` 그대로 출력

### 정석 풀이

```python
n = int(input())
answer = -1
for five in range(n // 5, -1, -1):      # 5kg 봉지를 많이 쓰는 것부터
    rest = n - 5 * five
    if rest % 3 == 0:                   # 나머지를 3kg로 딱 나눌 수 있으면
        answer = five + rest // 3
        break
print(answer)
```

- 봉지 수를 줄이려면 큰 봉지(5kg)를 최대한 많이 써야 함 → 5kg 개수를 **큰 것부터** 줄여 가며 확인
- 나머지가 3으로 나눠지는 **첫 순간이 최소** → 바로 `break`
- 5kg 개수가 정해지면 3kg 개수는 `(N - 5i) // 3`으로 계산됨 → `j`를 for문으로 찾을 필요 없음

| 방법 | 두 봉지 개수 전부 대입 | 5kg 개수만 큰 것부터 (그리디) |
