# 1436. 영화감독 숌

- 링크: https://www.acmicpc.net/problem/1436

- 푼 날짜: 2026-11-24
- 소요 시간:
- 결과: 성공

## 접근 방법

- 1부터 1씩 늘리며 종말의 수인지 확인하고, N번째로 찾은 수를 출력
- `check(n)`: 숫자 연산으로 666 포함 여부 확인
  - `n % 1000 == 666`이면 끝 세 자리가 666
  - 아니면 `n //= 10`으로 한 자리씩 지우며 모든 위치 확인

## 다른 풀이에서 배운 점

- 정석 풀이와 같은 방식 (하나씩 늘리며 확인하는 브루트포스)
- N = 10,000일 때 답이 2,666,799 → 약 270만 번 확인이라 전부 돌아도 됨
- 숫자 안에 특정 패턴이 있는지는 문자열로 바꿔 `'666' in str(n)`으로 확인하는 경우가 많음
