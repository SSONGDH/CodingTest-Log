# 진료과별 총 예약 횟수 출력하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/132202
- 분류: GROUP BY
- 푼 날짜:
- 결과: 성공 (날짜 조건 검색)

## 핵심

- 2022년 5월만: `>= '2022-05-01' AND < '2022-06-01'`
- 진료과별로 묶고 예약 건수 오름차순, 같으면 진료과 코드 오름차순
- 한글/공백이 들어간 별칭은 따옴표로 감쌈

## 막혔던 부분

- 날짜 범위 조건 쓰는 법을 몰랐음

## 배운 점

- `APNT_YMD`는 시간까지 있는 DATETIME이라 `<= '2022-05-31'`로 쓰면 **5월 31일 00:00:00까지만** 포함되고 그날 오후 예약이 빠짐
  - 그래서 "다음 달 1일 미만(`<`)"으로 쓰는 게 안전
- 다른 방법: `DATE_FORMAT(APNT_YMD, '%Y-%m') = '2022-05'` 또는 `YEAR(APNT_YMD) = 2022 AND MONTH(APNT_YMD) = 5`
